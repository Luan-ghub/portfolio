# Portfólio de Projetos — Luan

Página pessoal para apresentação de projetos em Análise e Ciência de Dados, com foco em soluções aplicadas a problemas de negócio, qualidade de dados e visualização interativa.

## Sobre o portfólio

O site reúne informações profissionais, competências técnicas, projetos recentes e formas de contato. A página foi construída sobre o template **Editorial**, do [HTML5 UP](https://html5up.net/), e personalizada de forma pessoal.

## Projetos apresentados

### Pipeline de Qualidade dos Microdados do ENEM 2025

Projeto de auditoria, limpeza, padronização e validação dos microdados públicos disponibilizados pelo Inep.

- [Repositório](https://github.com/Luan-ghub/enem-2025-data-quality-pipeline)
- [Base oficial do Inep](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/enem)

### Dashboard Interativo Curry Company

Dashboard gerencial para acompanhamento de indicadores logísticos e de desempenho de uma empresa de food delivery.

- [Repositório](https://github.com/Luan-ghub/curry_company)
- [Dashboard](https://currycompany-project.streamlit.app/)

### Dashboard Interativo Zomato

Dashboard analítico para exploração de dados globais de um marketplace de restaurantes.

- [Repositório](https://github.com/Luan-ghub/Zomato)
- [Dashboard](https://zomatodash.streamlit.app/)

## Estrutura principal

```text
portfolio/
├── assets/        # estilos, scripts, fontes e arquivos Sass
├── images/        # imagens do perfil e capas dos projetos
├── index.html     # página principal
├── LICENSE.txt    # licença do template
└── README.md      # documentação do portfólio
```

## Atualização do conteúdo

Os textos, links e projetos são mantidos em `index.html` e atualizados conforme o upload de novos projetos.
